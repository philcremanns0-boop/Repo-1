# Money-Loop

Autonomes Arbeitssystem: Ein nächtlicher Lauf (Claude Code Scheduled Task in der Cloud) liest `plan.md`, erledigt die nächste Aufgabe, lässt sie von einem Prüf-Agenten kontrollieren, schreibt `log.md` und `metrics.csv` und pusht auf den Branch `claude/passive-income-ai-loops-dkzsqw`. Steuerung vom iPad/Handy über den Code-Tab der Claude-App.

## Dateien

| Datei | Zweck |
|---|---|
| `plan.md` | Backlog und Experimente, einzige Quelle der Wahrheit |
| `log.md` | Was jeder Lauf getan hat (anhängen, nie löschen) |
| `metrics.csv` | Zahlen pro Experiment, Grundlage für Weiter/Abbrechen |
| `memory/recherche.md` | Verdichtete Recherche mit Quellen (RAG-Wissen) |
| `agents/*.md` | Rollen und RAG-Regeln pro Agent |
| `routine-prompt.md` | Selbsterklärender Prompt des nächtlichen Laufs |
| `out/` | Fertige Pakete zum Veröffentlichen (Texte, Seiten, Dateien) |

## Was nur du tun kannst

Der Loop darf nichts veröffentlichen, versenden oder bezahlen. Er bereitet alles so vor, dass du es nur noch freigibst:

1. Gewerbe/Steuer klären (Finanzamt oder Steuerberater), Impressumsdaten liefern.
2. Konten anlegen: Digistore24, Etsy, Fiverr/Malt/Upwork.
3. Fertige Pakete aus `out/` einstellen oder freigeben.

Freigaben kommen als Liste oben in `plan.md` unter "Wartet auf Freigabe".
